### Part B

``` r
tab2 = matrix(c(30, 4, 12, 14), nrow = 2, byrow = TRUE)
pA = sum(tab2[1, ]) / 60
pB = sum(tab2[, 1]) / 60
print(c(pA = pA, pB = pB, diff = pA - pB))
```

    ##         pA         pB       diff 
    ##  0.5666667  0.7000000 -0.1333333

``` r
print(mcnemar.test(tab2, correct = TRUE))
```

    ##  McNemar's Chi-squared test with continuity correction
    ## 
    ## data:  tab2
    ## McNemar's chi-squared = 3.0625, df = 1, p-value = 0.08012
